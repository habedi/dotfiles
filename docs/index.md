# Dotfiles

Personal dotfiles repository: shell scripts, editor and Git configuration, language cheatsheets, and AI agent skills. Source on [GitHub](https://github.com/habedi/dotfiles).

## Cheatsheets

Single-page references with collapsible deep-dive examples.

- [**Zig 0.16.0**](zig.md) — syntax, optionals and errors, comptime, allocators, build system, std library, and C interop.
- [**Rust** (stable)](rust.md) — ownership and borrowing, traits and generics, iterators, async with tokio, cargo, and error handling.

## What else is in the repository

- **`scripts/`** — bash scripts for system setup and maintenance.
- **`git/gitconfig`** — personal Git configuration.
- **`skills/`** — Markdown skill files for AI agents.
- **`.editorconfig`** — editor defaults.

See the [README](https://github.com/habedi/dotfiles#readme) for the full layout.
