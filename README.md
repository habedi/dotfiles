## Dotfiles

This repository contains my dotfiles and other handy files and scripts that I use for work or my personal projects.
It includes configurations for the following programs:

- **Python-related files**
    - [pyproject.toml](pyproject.toml)
- [Git-related files](git)
- [Useful scripts](scripts)
- **Editor configurations**
    - [editorconfig](.editorconfig)
- **AI agent skills**
    - [slopify](skills/slopify/SKILL.md)
- **Cheatsheets** (single-file HTML, deployed via GitHub Pages by [docs.yml](.github/workflows/docs.yml))
    - [Zig 0.16.0](cheatsheets/zig/index.html)
    - [Rust (stable)](cheatsheets/rust/index.html)
